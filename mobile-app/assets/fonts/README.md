Cardo Bold is retained as an optional local font asset. The CreditPick wordmark currently uses the platform system font.

Source: [Google Fonts — Cardo](https://github.com/google/fonts/tree/main/ofl/cardo).
License: [SIL Open Font License 1.1](./OFL-Cardo.txt).

The font file contains the actual bold weight; no synthetic bold or italic is applied.
